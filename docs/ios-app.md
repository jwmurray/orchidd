# Orchid — iPhone app

Status: built 2026-10-17 (v1). Source in `ios/`.

## Goal

A native iPhone app for the orchid room that reads the same orchidd server as the
web page. Three tabs on a bottom tab bar, left to right:

| Tab | Icon (SF Symbol) | Shows |
|---|---|---|
| **Graph** | `chart.xyaxis.line` | Temperature, humidity and heater-plug on/off over 24 h, 48 h or 7 days |
| **Settings** | `gearshape` | Thermostat settings (edit + save) and the server address |
| **Numbers** | `number` | Current values, plus 24 h and 7 day highs and lows |

## Server

- Default address `https://orchid.gardenway.org` — tailnet-only (Caddy on
  gardenway → orchidd on RMiMac :8000). The phone must have Tailscale on.
- Changeable in Settings → Connection (stored in `UserDefaults`).
- No login: the tailnet is the access control, as for budget and health.

Endpoints used (all existing; no server change):

| Endpoint | Used by |
|---|---|
| `GET /api/status` | Numbers (now), Graph header |
| `GET /api/stats` | Numbers (24 h / 7 d high-low) |
| `GET /api/data?days=N` | Graph series (`t` ms epoch, `tempF`, `hum`) |
| `GET /api/heater?days=N` | Graph heater bands + step line |
| `GET/PUT /api/settings` | Settings (PUT takes a partial patch) |

## Screens

**Graph.** Range picker (24 h · 48 h · 7 days). Three stacked charts sharing the
time axis: temperature (tall, heater-on periods shaded), humidity, and a short
heater strip drawn as a step line (raised = on). Pull to refresh; auto-refresh
every 60 s while visible.

**Settings.** Form with mode (Auto / Off), day start and end, day and night
minimums, hysteresis, high cutoff, alert threshold, stale-sensor minutes and
alerts on/off. Save sends only the thermostat fields as a patch; the server
validates and returns the saved settings. Connection section holds the server
address.

**Numbers.** Large current temperature and humidity, then sections:
*Now* (heater, period and setpoint, last reading), *Last 24 hours* and
*Last 7 days* (temperature high/low, humidity high/low).

## Build

- SwiftUI + Swift Charts, iOS 17+, iPhone only. Project generated by XcodeGen
  from `ios/project.yml` (`cd ios && xcodegen`).
- Bundle id `org.jwmfirm.orchid`, team H3597W8S59 (automatic signing).
- Tests: `OrchidTests` — JSON decoding of every endpoint, heater step-line
  clipping, HH:MM conversion, window lookup. No network.

## Install on a phone

Either connect the iPhone to the Mac once (Xcode → Window → Devices, trust,
Developer Mode on) and run the `Orchid` scheme to it, or upload to TestFlight
(needs an App Store Connect app record for `org.jwmfirm.orchid`).
